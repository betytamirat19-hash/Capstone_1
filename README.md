# Capstone 1: Business Analysis with SQL and Excel

Project Description

This project analyzes sales data for EmporiUm, a fictional bookstore and retail business. Using SQL and Excel, I will analyze sales performance, revenue trends, monthly transactions, product categories, and store performance.

Sales Territory
My assigned sales territory is Connecticut.

Tools 
- MySQL Workbench (SQL)
- Microsoft Excel (PivotChart)
- Git and GitHub (version control)
- Power Point (Presentation)

Project Goal
The goal is to understand sales performance and provide recommendations for where to focus sales attention in the next quarter.

## Questions 
1. Total revenue and the period the data covers
2. Revenue breakdown by year and month
3. Connecticut revenue compared with the East region
4. Transactions per month and average transaction amount by product category
5. Ranking of store performance in Connecticut
6. Recommendation on where to focus sales in the next quarter

## Files
- `Tamirat_sales_analysis.sql`: SQL queries and recommendation
- `tamirat_territory_chart.xlsx`: Excel PivotChart
