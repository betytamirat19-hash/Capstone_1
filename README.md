# Capstone 1: Business Analysis with SQL and Excel

## About the Project
This project is a business analysis for **EmporiUm**, a fictional student bookstore chain that sells books, tech products, art supplies, and other products both in-store and online. Sales are organized by region, and each region is divided into sales territories.

As a data analyst, I used **SQL (MySQL Workbench)** to answer a sales manager's questions about one sales territory, and **Excel (PivotChart)** to visualize the results.

## My Sales Territory
**Connecticut** (in-store territory, East region)

## Questions Answered
1. Total revenue and the period the data covers
2. Revenue breakdown by year and month
3. Connecticut revenue compared with the East region
4. Transactions per month and average transaction amount by product category
5. Ranking of store performance in Connecticut
6. Recommendation on where to focus sales in the next quarter

## Tools Used
- MySQL Workbench (SQL)
- Microsoft Excel (PivotChart)
- Git and GitHub (version control)

## Files
- `Tamirat_sales_analysis.sql`: SQL queries and recommendation
- `tamirat_territory_chart.xlsx`: Excel PivotChart
